이 웹사이트를 무료로 배포하는 3가지 방법

단일 HTML 파일이므로 서버 없이 누구나 3분 안에 무료 사이트로 오픈할 수 있습니다.

방법 1. Netlify Drop (가장 쉬움, 30초 완성) 추천

1. 지금 이 코드를 복사하여 내 컴퓨터에 index.html 파일로 저장합니다.
2. Netlify Drop(app.netlify.com/drop) 사이트에 접속합니다.
3. index.html이 들어있는 폴더를 화면에 드래그하면 즉시 나만의 전용 웹 링크(URL)가 생성됩니다!

방법 2. GitHub Pages (영구 무료 호스팅)

1. GitHub 계정에서 새 저장소(New Repository)를 만듭니다.
2. 이 코드를 index.html이라는 이름으로 업로드합니다.
3. 저장소의 Settings > Pages 메뉴에서 Branch를 main으로 지정 후 Save를 누르면 https://아이디.github.io/저장소이름 링크가 바로 열립니다.

방법 3. Vercel

Vercel에 가입한 후 GitHub 저장소를 연동하면 클릭 한 번으로 자동 배포되며 무료 SSL 인증서(https)까지 즉시 적용됩니다.
